# Unitree Go2 MuJoCo WASM

Editable browser app for the Unitree Go2 mjlab velocity policy.

## Layout

- `src/` - React, TypeScript, MuJoCo WASM runtime, ONNX policy loop, controls.
- `public/assets/config.json` - app/project/scene registry.
- `public/main/assets/go2_velocity/scene.mjz` - bundled MuJoCo scene.
- `public/main/assets/go2_velocity/go2_mjlab_velocity.json` - policy config.
- `public/main/assets/go2_velocity/go2_mjlab_velocity.onnx` - ONNX policy.

## Commands

```bash
npm install
npm run dev
```

```bash
npm run build
npm run serve
```

The server adds COOP/COEP headers required by the WASM runtime.

## GitHub

This repository should commit `src/`, `public/`, `package.json`, and
`package-lock.json`. Do not commit `node_modules/` or `dist/`; both are
regenerated by npm.
